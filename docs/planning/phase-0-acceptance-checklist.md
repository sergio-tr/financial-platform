# Phase 0 Acceptance Checklist

Phase 0 is complete only when:

- [ ] Decision Register is committed.
- [ ] All accepted ADRs are committed and indexed.
- [ ] `AGENTS.md` and project rules are installed.
- [ ] Security-sensitive paths are excluded from Git/agent context.
- [ ] Architecture baseline and bounded-context map are reviewed.
- [ ] WebSocket protocol and AsyncAPI ownership rules are reviewed. (R26/R42)
- [ ] Connector SPI/capability rules are reviewed.
- [ ] Portfolio X-Ray specification is reviewed.
- [ ] Temporal workflow boundary is reviewed.
- [ ] Security architecture/threat model is reviewed. (R41/R43/R46/R47)
- [ ] Dashboard/UX system is reviewed.
- [ ] Master implementation plan is approved.
- [ ] Cursor operating model and stop conditions are approved.
- [ ] Repository skeleton has no production secrets or real portfolio data.
- [ ] No application feature implementation has started ahead of these governance artefacts.
- [ ] Traceability graph/schema exists and validates. (R37/R39)
- [ ] Requirements catalogs exist under `docs/requirements/functional/**` and `docs/requirements/nfr/**`. (R40)
- [ ] Public API registry structure exists. (R35)
- [ ] Verification catalog structure exists. (R44)
- [ ] Design manifest structure and tokens directory exist. (R45)
