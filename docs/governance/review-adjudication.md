# Review Adjudication (R36)

Status: CANONICAL

Decisions requiring adjudication identify:
- Authority and sources (ADRs, planning packs, manifests).
- Specific files/IDs under review.
- Criteria: architectural consistency, security posture, contract compatibility, traceability completeness, and documentation clarity.

Outcomes:
- ACCEPTED, REVISE, or REJECTED with rationale.
- Traceability updated (see R37/R39) to reflect adjudication result.

Traceability adjudication (R39) is documented under `docs/governance/traceability/review-adjudication.md`.
